# Betall

An Chrome extension to identify profitable opportunities in prediction markets.

# Installation

1. Download the latest release from [GitHub Releases](https://github.com/C0ldSmi1e/betall-frontend/releases)
2. Extract the downloaded zip file
3. Open Chrome and navigate to `chrome://extensions/`
4. Enable "Developer mode" in the top right corner
5. Click "Load unpacked" and select the extracted extension folder
6. The Betall extension should now appear in your browser toolbar
